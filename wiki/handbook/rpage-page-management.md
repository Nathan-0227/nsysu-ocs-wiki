## 一句話重點

> 「頁面管理」決定網頁**長什麼樣子**：可以調整 CSS、設定頁首和頁尾，並把各種模組放進頁面。

## 這是什麼

| 功能 | 用途 |
|---|---|
| 頁面樣式變更 | 套用學校的版型 |
| 頁面頭部／底部建立 | 設定頁首（header）和頁尾（footer） |
| 首頁畫面設定 | 決定首頁要放哪些模組 |
| 樣式設定 | 調整 CSS |
| 模組列表 | 把模組放進頁面（見 [[rpage-modules]]） |

### 個別頁面設定

單則資訊可以有自己的頁面佈局。在資訊列表點該則的「**版面**」圖示，就會進入「個別頁面設定」：

- 上方按鈕：儲存、頁面佈局、樣式設定、模組列表、重新整理；可切換繁體／English。
- 頁面頭部設定：預設頁首頭部（不用改）。
- 中間：顯示路徑模組、資訊明細模組、選單＞【僑生】選單。
- **頁面底部設定：選「僑外組專用（新）」** ← 本專區唯一的要求。
- 按「儲存」，看到「修改操作成功」就完成了。

改過之後，列表的「頁面」欄會從「預設」變成「**個別**」。

## 在僑生專區怎麼用

- 一般公告用「預設」就好。
- 有特別調整版面的資訊，**footer 一定要換成「僑外組專用（新）」**（見 [[publish-announcement]] 步驟 10）。
- 想讓頁面更好讀時（優化），可以在這裡調整 CSS。

## 注意事項

- 修改樣式前先截圖記下原本的設定，改壞了才能還原。
- 改完要用電腦和手機各看一次。
- 頁首、模組設定沒有需要就不要動。
