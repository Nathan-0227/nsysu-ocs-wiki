## 一句話重點

> 「資訊管理」是**最常用**的後台功能：所有公告都在這裡新增，所有分類也在這裡管理。

## 這是什麼

Rpage 把網站內容分成「**分類**」和「**資訊**」。分類像資料夾，可以有上下層；資訊是放在分類裡的一則則公告或頁面。

### 僑生專區的分類結構

| 排序 | 分類 | 前台對應 |
|---|---|---|
| 1 | 僑輔項目 | 入學輔導、居留、保險、工作許可等常設頁面 |
| 2 | 最新消息 | 首頁的最新消息分頁 |
| 3 | 獎助學金 | 獎助學金公告（置頂常設項目＋公告） |
| 4 | 徵才 & 工讀 | 徵才、兼職、實習轉知 |
| 5 | 法令規章 | 法規分類頁籤 |
| 6 | 學生社團 | 僑聯會與各同學會 |
| 7 | 僑生活動 → 僑生活動資訊／僑生活動回顧 | 活動公告與照片回顧 |
| 8 | 聯絡我們 | |
| 9 | 其他 | |

另外還有後臺區與測試區、表單下載、僑輔等分類，共 12 筆。

### 分類列表的功能

| 按鈕 | 用途 |
|---|---|
| 新增 | 在這個分類新增一則資訊（見 [[publish-announcement]]） |
| 刪除／刪除多語 | 「刪除」只刪目前語系；「**刪除多語**」會連英文版一起刪 |
| 加入分類／移出分類 | 讓一則資訊同時出現在多個分類 |
| 排序 | 調整列表順序（例如讓常設項目置頂） |
| 發佈總綱 | 發佈到總網 |
| 繁體／English | 切換語系 |

列表欄位：資訊名稱、點選次數、發佈日期、下架日期、頁面（預設／個別）、操作（編輯、版面）。

## 在僑生專區怎麼用

- **新增公告**：照 [[publish-announcement]]，標題照 [[naming-rules]]。
- **英文版**：繁體儲存後切到「English」，自己翻譯標題和內容，並把資訊狀態改成**有效（Valid）**。
- **點選次數**可以看出同學最常看哪些資訊，例如常設的「獎助學金一覽表」點選數比一般公告高很多，可以作為優化的參考。

## 注意事項

- 要刪除時先想清楚：只想刪英文版就用「刪除」，不要按到「刪除多語」。
- 分類下已經有資訊或帶有連結網址的話，就不能拿來當上級分類。
- 「共享資訊」「行事曆發佈」本專區不用，維持預設即可。
