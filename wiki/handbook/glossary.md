## 一句話重點

> 看不懂後台或 SOP 裡的名詞，先查這一頁。

## Rpage 後台用語

| 名詞 | 意思 | 詳見 |
|---|---|---|
| **資訊** | 一則公告或一個頁面的內容，在「資訊管理」新增 | [[rpage-info-management]] |
| **分類** | 資訊的資料夾，例如「獎助學金」「僑生活動資訊」；可以有上下層 | [[rpage-info-management]] |
| **加入分類／移出分類** | 讓同一則資訊同時出現在多個分類 | [[publish-announcement]] |
| **總綱** | 新增資訊視窗右側的頁籤之一，與發佈到總網有關 | — |
| **資訊狀態** | 有效／無效；英文版要記得改成有效（Valid） | [[rpage-info-management]] |
| **下架日期** | 資訊在前台消失的日期；本專區一律維持 2099-12-31 | [[publish-announcement]] |
| **資訊圖檔** | 新增資訊視窗的分頁，用來上傳照片（大圖）和封面 | [[update-event-review]] |
| **大圖** | 在「資訊圖檔」上傳的照片，可加「大圖說明」並排序 | [[update-event-review]] |
| **頁面：預設／個別** | 「預設」套用分類的版面；「個別」表示這則有特別調整頁面佈局 | [[rpage-page-management]] |
| **頁面底部（footer）** | 頁面最下方的區塊；個別頁面要選「僑外組專用（新）」 | [[rpage-page-management]] |
| **模組** | 組成網頁的積木，例如公告模組、連結模組、廣告模組 | [[rpage-modules]] |
| **文檔** | 存在後台的檔案（JS、圖片、PDF），可用網址在 HTML 中引用 | [[rpage-documents]] |
| **刪除／刪除多語** | 「刪除」只刪目前語系；「刪除多語」會連英文版一起刪 | [[rpage-info-management]] |

## 本專區用語

| 名詞 | 意思 | 詳見 |
|---|---|---|
| **公告** | 由本校（僑外組）發出的資訊 | [[naming-rules]] |
| **轉知** | 資訊來自外部（其他大學、基金會、校內其他單位），本專區只是轉發 | [[naming-rules]] |
| **承辦人** | 僑外組僑生業務承辦人，發布前要先確認 | [[publish-announcement]] |
| **中山僑聯 FB** | 僑生聯誼會的 Facebook 粉專；官網發布後馬上轉發 | [[publish-announcement]] |
| **nsysuocsphoto** | 活動照片的 FB 來源 | [[update-event-review]] |
