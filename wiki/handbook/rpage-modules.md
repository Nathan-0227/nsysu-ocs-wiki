## 一句話重點

> **模組化是 Rpage 形成各種頁面的方式。** 一頁網頁就是幾個模組排在一起，不同頁面有不同功能，就是因為放了不同的模組。

## 這是什麼

把模組想成積木：每個模組負責一種功能，在「頁面管理」裡把需要的模組排進頁面，就組成一頁（見 [[rpage-page-management]]）。

### 常見模組

| 模組 | 用途 |
|---|---|
| 公告模組 | 公佈欄，顯示一個分類的公告列表 |
| 連結模組 | 一組網站連結 |
| 廣告模組 | 大圖輪播，顯示活動、獎項等 |
| 選單模組 | 側邊選單，例如僑生專區左側的「【僑生】選單」 |
| 頁籤模組 | 把多組內容合併成頁籤，例如首頁「最新消息／獎助學金公告／活動公告／徵才 & 工讀／其他」 |
| 表單模組 | 報名活動、意見反映 |
| 自訂模組 | 自己寫 HTML 內容 |
| 資訊明細模組 | 顯示單則資訊的詳細內容 |
| 顯示路徑模組 | 顯示麵包屑（目前位置） |

### 例子：一則資訊的頁面由哪些模組組成

以「個別頁面設定」看到的一則資訊為例：

```
頁面頭部（預設頁首頭部）
├── 顯示路徑模組
├── 資訊明細模組
├── 選單 >【僑生】選單
頁面底部（僑外組專用（新））
```

## 在僑生專區怎麼用

- 需要新的頁面版型時，先想「同學需要看到什麼」，再挑模組組合。
- 首頁的公告頁籤就是頁籤模組＋多個公告模組組成的。

## 注意事項

- 改模組會影響所有用到它的頁面，修改前先確認哪些頁面有放這個模組。
- 網站採 RWD，手機上多欄會變成單欄，排完模組要用手機看一次。
