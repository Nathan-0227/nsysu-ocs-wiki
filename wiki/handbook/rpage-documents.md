## 一句話重點

> 「文檔管理」是後台的**檔案倉庫**：JS、圖片、檔案先上傳到這裡，再把網址寫進 HTML 裡使用。

## 這是什麼

- 存放 JS 檔、圖片、檔案的地方。
- 上傳後每個檔案都有一個網址，可以在 HTML（例如自訂模組、頁面頭部或底部的語法、資訊的「詳細說明」HTML 模式）裡引用。
- 例如網站 logo：先上傳圖片到文檔，再把圖片路徑寫進頭部或底部語法。

## 在僑生專區怎麼用

### 用 JS 做出特別的功能
1. 把寫好的 `.js` 檔上傳到文檔管理。
2. 複製檔案網址。
3. 在需要的地方（自訂模組或 HTML 內容）用 `<script src="檔案網址"></script>` 引入。
4. 到前台確認功能正常，手機也要測一次。

### 和「資訊圖檔」的差別
| | 文檔管理 | 資訊圖檔 |
|---|---|---|
| 放什麼 | JS、共用圖片、共用檔案 | 單則資訊的照片（大圖）與封面 |
| 誰用 | 多個頁面共用 | 只屬於那一則資訊 |

活動照片請用資訊圖檔（見 [[update-event-review]]）。

## 注意事項

- 檔案取有意義的名稱，下一任才知道它是做什麼的。
- 刪除文檔前，先確認沒有頁面在用它，否則頁面會壞掉。
- 上傳的 JS 要留一份說明：做什麼用、用在哪些頁面。
