## 什麼時候用

（活動結束後的照片紀錄請改用 [[update-event-review]]。）

有一則獎學金、活動、工讀或一般消息要在僑生專區發布時。資訊來源有兩種：

| 來源 | 例子 | 先做什麼 |
|---|---|---|
| **承辦人通知** | 僑外組僑生業務承辦人交辦的獎學金公告 | 直接進入步驟 2 |
| **自己找到** | 在其他大學或其他單位網站看到適合僑生的資訊 | 先照 [[verify-external-info]] 查證 |

## 步驟

> ⏰ **兩個最重要的提醒**：① 發布前**再確認一次截止日期**；② 資訊有效期有限，確認後**盡快公布**。

1. **（外部資訊）查證來源**：照 [[verify-external-info]] 確認是官方來源、還在有效期限內。
2. **和承辦人討論**（盡快，資訊有時效）：這則可不可以公告？用「公告」還是「轉知」？要放在哪個分類？
   - 承辦人不在、但有急件時：**直接用 LINE 聯絡承辦人，確認後才發布**，發布後再告知。不可以沒確認就先發。
3. **進入正確的分類**：後台「僑生學生位」→ 依資訊類型點選分類（獎助學金、徵才 & 工讀、僑生活動 → 僑生活動資訊……）→ 點「**新增**」。
4. **填寫「新增資訊」的基本資料**：

   | 欄位 | 必填 | 怎麼填 |
   |---|---|---|
   | 資訊名稱 | ✅ | 依 [[naming-rules]] 加前綴與年度 |
   | 連結網址 | | **轉知**：填外部原公告網址；**公告**：留空，內容寫在「詳細說明」 |
   | 新視窗開啟 | | 有填連結網址時選「是」 |
   | 資訊狀態 | | 「有效」 |
   | 發佈日期 | ✅ | 預設今天 |
   | 下架日期 | ✅ | 維持預設 **2099-12-31**（目前分類內所有公告都是這個值） |
   | 詳細說明 | | 公告內文 |
   | 分類 | | 確認右側「分類」已是正確分類 |

5. **封面與照片**：需要時在「**資訊圖檔**」分頁上傳。其他分頁（屬性、共享資訊、行事曆發佈）不用動。
6. **附件**：在「附件」分頁上傳申請表、辦法等檔案（檔名改成固定格式；格式依承辦人指示）。
7. **調整排版**：「詳細說明」需要表格、粗體、連結時改用 **HTML** 模式調整，避免整段文字擠在一起。
8. 按「**新增並返回**」。
9. **需要放在多個分類時**：在分類列表勾選這則公告 →「**加入分類**」，例如同時放進「最新消息」和「獎助學金」。
10. **（有特別調整版面時）換成僑外組專用 footer**：在列表點這則的「版面」圖示 → 進入「個別頁面設定」→「頁面底部設定」選「**僑外組專用（新）**」→「儲存」，看到「修改操作成功」即可。其他設定（頁首、模組）維持不動。完成後列表的「頁面」欄會顯示「個別」。
11. **英文版**：切換到「English」，自己翻譯標題與內容後發布。
12. 到前台檢查中文版與英文版，**再核對一次截止日期**。
13. **官網發布後馬上轉發到「中山僑聯」Facebook 粉專**，貼文格式：**標題＋重點＋官網連結**。
14. **同步到本站**：照 [[sync-to-wiki]]。

## 發布後的狀況處理

| 狀況 | 怎麼做 | 本站要不要同步 |
|---|---|---|
| 發現內容有錯 | **直接編輯原公告**（不另發、不加前綴） | 要：依 [[sync-to-wiki]] 修正對應頁面 |
| 截止日延長 | **直接改原公告內容** | 要：更新獎學金頁的 `deadline`，首頁狀態會自動變回「開放中」 |
| 獎學金已截止 | **留著不動**（下架日期維持 2099-12-31） | 不用：本站會自動顯示「已截止・預計明年 X 月公告」 |

## 檢查清單

- [ ] 外部資訊已查證來源與期限
- [ ] 已和承辦人確認可以公告
- [ ] 截止日期已再核對一次（標題、內文、附件一致）
- [ ] 標題符合 [[naming-rules]]
- [ ] 分類正確；需要多個分類時已用「加入分類」
- [ ] 附件都能下載、檔名符合格式
- [ ] 有調整版面的公告，footer 是「僑外組專用（新）」
- [ ] 英文版已發布
- [ ] 轉知類的外部連結點得開
- [ ] 前台列表看得到、排版正常
- [ ] 已馬上轉發到中山僑聯 FB（標題＋重點＋官網連結）
- [ ] 已同步到本站

## 常見錯誤

| 錯誤 | 後果 | 怎麼避免 |
|---|---|---|
| 截止日期寫錯或沒再核對 | 同學錯過申請，或在截止後才送件 | 發布前、發布後各核對一次截止日 |
| 拖太久才公布 | 同學準備時間不夠，甚至公告時已截止 | 確認後盡快公布 |
| 外部資訊沒查證就轉發 | 公告了過期或非官方的資訊 | 先做 [[verify-external-info]] |
| 附件裡的申請表連到錯的檔案 | 同學下載到錯的表（例：獎學金與助學金連到同一個檔案，見 [[ocah-scholarship-grant]]） | 發布後逐一點開附件 |
| 網頁摘要和內文的條件不一致 | 同學看到兩種 GPA 標準 | 「簡單說明」要跟內文一起更新 |
